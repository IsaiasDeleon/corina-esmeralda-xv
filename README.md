# Esmeralda — XV Años

Invitación digital independiente para **Corina Esmeralda**, el **31 de octubre de 2026**. Paleta: `#14463c` y `#009473`.

- Invitación: https://isaiasdeleon.github.io/corina-esmeralda-xv/
- Catálogo: https://isaiasdeleon.github.io/corina-esmeralda-xv/catalogo/

Todos los datos personalizables están en [`config.js`](config.js): nombre, fecha, mamá, padrinos, ceremonia, recepción, horarios, itinerario, código de vestimenta, galería, mapas, canción y WhatsApp.

Coloca las imágenes WebP y el audio en `assets/corina/hero/`, `assets/corina/gallery/`, `assets/corina/venues/` y `assets/corina/audio/`. Después agrega las rutas relativas a `config.js`. La galería acepta de una a cinco fotografías. Mientras no existan imágenes, música, mapas o teléfono, la invitación muestra marcadores o estados informativos sin enlaces falsos.

El sitio es HTML, CSS y JavaScript estáticos, sin dependencias. GitHub Actions publica la raíz del repositorio en GitHub Pages al hacer push a `main`.
